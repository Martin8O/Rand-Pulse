# Rand Pulse

Modern randomization and decision-making web app designed for fast, engaging, and intuitive user interaction.

Live Demo: [Rand Pulse Live App](https://randpulse.lovable.app/)

Repository: [Rand Pulse GitHub Repository](https://github.com/Martin8O/Rand-Pulse)

---

## Overview

Rand Pulse is a sleek and responsive random generator application focused on simplicity, speed, and modern UI/UX.

The project provides an interactive environment for generating randomized outcomes, helping users with quick decisions, inspiration, entertainment, and dynamic interactions.

Built with a modern frontend stack and optimized for responsiveness, the app combines:

* Clean modern design
* Fast interactions
* Smooth user experience
* Mobile-friendly layout
* Scalable architecture

# Getting Started

## Prerequisites

Make sure you have installed:

* Node.js
* npm or yarn

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Martin8O/Rand-Pulse.git
```

Navigate into the project directory:

```bash
cd Rand-Pulse
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

# Production Build

Build the application:

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```
